# 🏫 스마트 좌석 배치 시스템 (Smart Seating Arrangement System)

**스마트 좌석 배치 시스템**은 선생님들의 학급 경영과 자리 배치 업무를 획기적으로 줄여주기 위해 개발된 웹 기반 프로그램입니다. 나이스(NEIS) 명렬표 엑셀 파일을 그대로 업로드하여 1초 만에 사진과 이름을 세팅하고, AI 알고리즘을 통해 짝꿍과 기피 학생을 고려한 최적의 자리를 무작위로 배치할 수 있습니다.

> **보안성 안내**: 이 시스템은 웹상에서 실행되지만 서버로 어떠한 데이터도 전송하거나 저장하지 않습니다. 오직 접속하신 선생님의 브라우저(PC) 내에서만 동작하므로 학생들의 개인정보와 사진이 완벽하게 보호됩니다.

---

## 🚀 시작하기 (접속 방법)
별도의 프로그램 설치나 다운로드가 필요 없습니다. 아래 링크를 클릭하여 웹 브라우저(Chrome, Edge 등)에서 바로 실행하세요.

🔗 **[스마트 좌석 배치 시스템 바로가기](https://kimjongho1004.github.io/smart-seating/)**

초기 화면의 **[👇 좌석 배치를 시작하려면 화면을 클릭하세요! 👇]** 영역을 마우스로 클릭하면 우측에 사이드바 메뉴가 나타납니다.

---

## 📖 단계별 사용 방법

### [STEP 1] 기본 설정
가장 먼저 학급의 기본 환경을 세팅합니다.

![STEP 1 기본 설정 화면](여기에_이미지_주소를_넣어주세요)

* **학급 정보 입력**: `예) 2학년 2반`과 같이 입력하면 상단 타이틀에 학급 이름이 표시되며 출력물에도 반영됩니다.
* **좌석 레이아웃 (가로칸 x 세로칸)**: 교실의 분단(열)과 줄(행) 수를 입력하고 `격자 적용`을 누릅니다. (미입력 시 인원수에 맞춰 자동으로 꽉 차는 격자가 생성됩니다.)
* **🪑 짝배열 모드**: 체크박스를 켜면 두 줄(2칸)마다 넓은 통로가 자동으로 생성되어, 실제 교실처럼 두 명씩 짝을 지어 앉는 형태의 레이아웃이 만들어집니다.

---

### [STEP 2] 명단 준비 (택 1)
학생 명단과 사진을 불러오는 단계입니다. 세 가지 방법 중 편한 것을 선택하세요.

![STEP 2 명단 준비 화면](여기에_이미지_주소를_넣어주세요)

1. **엑셀(.xlsx) 파일 선택 (추천 ⭐)**: 나이스에서 다운로드한 '사진 포함 명렬표' 엑셀 파일을 업로드하세요. 프로그램이 사진과 '번호+이름'을 1초 만에 자동 추출해 자리에 띄워줍니다.
2. **학생 사진 폴더 선택**: 사진 파일들을 직접 전체 선택하여 업로드합니다. (파일명은 `번호 이름.jpg` 형식을 권장합니다.)
3. **사진 없이 빈 좌석표 만들기**: 엑셀이나 사진 없이 수기 입력을 원할 경우 빈 좌석을 생성합니다.

---

### [STEP 3] 배치 실행
본격적으로 자리를 섞고 짝꿍/기피 등 특수 조건을 부여합니다.

![STEP 3 배치 실행 화면](여기에_이미지_주소를_넣어주세요)

* **🔗 짝꿍 설정**: 버튼을 켜고 나란히 앉힐 두 학생을 차례로 클릭하세요. (무지개색 짝꿍 뱃지 생성) 셔플 시 무조건 붙어 앉게 됩니다.
* **⛔ 기피 설정**: 버튼을 켜고 떨어뜨려 놓을 두 학생을 차례로 클릭하세요. (무지개색 기피 뱃지 생성) 셔플 시 상하좌우 및 대각선으로도 인접하지 않도록 AI가 띄워 놓습니다.
* **뱃지 취소**: 설정된 뱃지(짝꿍/기피)를 마우스로 클릭하면 해당 연결이 즉시 취소(삭제)됩니다. 다중 기피 설정도 가능합니다.
* **🎲 무작위 배치 시작**: 부여된 조건(짝꿍/기피/고정)을 모두 만족하는 최적의 자리를 찾아 3초 카운트다운 후 배치를 섞습니다.
* **빠른 배치 옵션**: 카운트다운 애니메이션을 생략하고 즉각적으로 셔플을 진행합니다.
* **🖥️ 꽉찬화면 실행**: 스크롤 없이 한 화면에 전체 좌석이 보이도록 화면을 꽉 채웁니다. (학생들과 모니터/TV로 화면을 공유할 때 유용합니다.)

---

### [STEP 4] 인쇄 / 저장
완성된 좌석표를 출력하거나 칠판 부착용으로 최적화합니다.

![STEP 4 인쇄 및 출력 화면](여기에_이미지_주소를_넣어주세요)

* **출력물 하단 당부 말씀**: `예) 무단 자리 이동 금지` 등 출력물 하단에 남길 코멘트를 자유롭게 입력합니다.
* **사진 숨기기 (가로 인쇄 모드)**: 사진을 숨기고 **이름과 번호의 크기를 극대화**합니다. 빈 공간을 자동으로 계산해 이름이 꽉 차게 커지며, 칠판 부착용으로 인쇄할 때 완벽하게 최적화됩니다.
* **🖨️ 학생용 출력**: 교탁을 바라보는 정방향 기준으로 깔끔하게 인쇄합니다.
* **🖨️ 교사용 출력**: 교탁에서 학생들을 바라보는 **역방향(상하좌우 반전)** 기준으로 완벽하게 뒤집어 인쇄합니다.

---

## 💡 유용한 꿀팁 (수동 조작 기능)

* **수동 자리 교체 (Drag & Drop)**: 마우스로 학생 카드를 끌어다가 다른 자리에 놓으면 즉시 두 자리가 맞바뀝니다.
* **수동 이름/번호 수정**: 학생 카드를 **더블클릭**하면 이름과 번호를 직접 수정할 수 있습니다. (전학생을 추가할 때 유용합니다.)
* **자리 고정 (📌 핀 고정)**: 학생 카드 우측 상단의 핀 아이콘을 클릭하면 자리가 고정(빨간 테두리)되어 무작위 배치를 돌려도 그 학생은 움직이지 않습니다.
* **모든 설정 해제**: 핀 고정, 짝꿍, 기피 등 모든 특수 설정을 한 번의 클릭으로 깔끔하게 초기화합니다.

---

## 💾 좌석 데이터 관리 (백업/복구)
* **현재 저장**: 현재 세팅된 학생 정보, 자리 위치, 짝꿍/기피 설정 데이터를 `.json` 파일 형태로 내 PC에 다운로드합니다.
* **불러오기**: 저장해두었던 `.json` 파일을 불러오면, 며칠이 지나도 당시의 좌석 배치와 조건들을 단 1초 만에 완벽히 복원할 수 있습니다. (교과 교실제나 이동 수업 시 활용하기 좋습니다.)
